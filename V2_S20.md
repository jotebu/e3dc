# E3DC v2.0 – S20 / Simple Mode V2.00

This branch extends the original IP-Symcon module for the E3/DC S20 generation while retaining the complete v1.6 implementation as `e3dc/module_legacy.php`.

## S10 / S20 Modbus comparison

- Both product generations use Modbus/TCP and the E3/DC Simple Mode register mapping.
- The basic registers used by this module for PV power, battery power, house consumption, grid power, SOC, wallbox data and DC strings remain compatible.
- The module already supports three MPP trackers and the extended inverter block starting at address 41000.
- Simple Mode V2.00 expands the power-meter area to registers 40105–40184. Version 2.0 therefore exposes 20 power-meter IDs (0–19) instead of 8.

## Important mapping note

In the old v1.80 implementation register 40137 was also used for `SG Ready-Status`. In the V2.00 layout this address lies inside the expanded power-meter range (power meter 8). For that reason the S20/V2.00 line must not interpret register 40137 as the legacy SG-Ready value.

## Verified S20 X PRO installation

Real-system test on 2026-08-23:

- Model (40020): `S20 X PRO`
- Firmware (40052): `H20_2026_02`
- Manufacturer (40004): `HagerEnergy GmbH`
- Supported-register count (40003): `1271`

The 32-bit signed power registers are not decoded correctly by current IP-Symcon when the ModBus Address remains at `Big-Endian (Standard)`. The result is a 16-bit word-order error (for example 3,604,480 W instead of about 55 W).

The following setting was verified on the real S20 X PRO:

`Byte-Reihenfolge = Little Endian (Byte Swap)`

Verified registers:

- 40068 – PV power
- 40070 – battery power
- 40072 – house-consumption power
- 40074 – grid power

After changing the byte order, all four values became plausible. One live sample was:

- PV: 6846 W
- Battery: +3957 W
- House consumption: 2829 W
- Grid: +44 W

The register descriptions retain the E3/DC sign convention:

- Battery power: positive = charging, negative = discharging
- Grid power: positive = grid consumption, negative = grid feed-in

The same byte-order handling must also be applied to the optional Int32 power registers 40076, 40078 and 40080.

### Powermeter verification

Powermeter IDs 0–6 were enabled and read on the same S20 X PRO:

- Powermeter 0 (40105): type `6` = `Wird nicht verwendet`; phase values observed around 0 / 2 / 2 W.
- Powermeter 1 (40109): type `0` = `N/A`; L1/L2/L3 = 0 W.
- Powermeter 2 (40113): type `0` = `N/A`; L1/L2/L3 = 0 W.
- Powermeter 3 (40117): type `0` = `N/A`; L1/L2/L3 = 0 W.
- Powermeter 4 (40121): type `0` = `N/A`; L1/L2/L3 = 0 W.
- Powermeter 5 (40125): type `0` = `N/A`; L1/L2/L3 = 0 W.
- Powermeter 6 (40129): type `1` = `Wurzelleistungsmesser` (root meter / grid connection point). A live sample showed L1 = +824 W, L2 = -121 W, L3 = -637 W, giving a phase sum of +66 W. This is consistent with the separate grid-power register 40074, allowing for sampling-time differences.

Conclusion: the physical root meter of this S20 X PRO installation is Powermeter ID 6. Positive phase values represent consumption on that phase and negative values represent feed-in. IDs 0–5 are unused/N/A on this installation.

**Do not enable Powermeter 8 or higher on the current test branch yet.** Powermeter 8 starts at register 40137, which currently collides with the legacy `SG Ready-Status` instance. The conflict must be removed in code before testing the extended V2.00 meter range.

## Implementation strategy

`e3dc/module.php` is a small v2.0 bootstrap. It defines the V2.00 device limits before loading the unchanged v1.6 implementation from `e3dc/module_legacy.php`. The legacy implementation already generates power-meter properties and addresses in loops, so the additional meters do not require duplicating the large module implementation.

The next code revision must explicitly configure the ModBus Address property for the verified 32-bit E3/DC power values so that manual byte-order changes are no longer required on IP-Symcon 7.x. It must also remove the legacy SG-Ready mapping at 40137 for the V2.00/S20 line before Powermeter IDs 8–19 are tested.
